# 🐸 أسطورة الضفدع النينجا — Ninja Frog Legend

لعبة منصّات بكسلية صعبة تعمل في المتصفح (HTML + CSS + JavaScript) في ملف واحد، بدون مكتبات أو بناء.

## المزايا
- 5 مراحل تزداد صعوبة، وكل مرحلة ثابتة بين المحاولات
- 4 أبطال بميزات مختلفة (الضفدع النينجا، الرجل المقنّع، الرجل الوردي، الرجل الافتراضي)
- قفزة مزدوجة، قفز عن الجدران، واندفاع سريع
- وحوش، مناشير، كرات شائكة، ألسنة لهب، منصّات متحركة وساقطة
- عناصر مساعدة: 🍒 درع، 🍈 تجميد الأعداء، 🍍 روح إضافية
- يعمل على الكمبيوتر (لوحة المفاتيح) وعلى الهاتف (أزرار لمس)

## التحكم
| الفعل | لوحة المفاتيح | الهاتف |
|---|---|---|
| الحركة | ← → أو A D | ◀ ▶ |
| القفز | مسافة أو ↑ أو W | ▲ |
| الاندفاع | Shift أو K | ⚡ |
| إعادة المرحلة | R | — |
| إيقاف مؤقت | P | ⏸ |

## التشغيل
افتح `index.html` في المتصفح، ولا حاجة إلى خادم.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه `index.html` و`README.md`.
2. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة يصبح الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## الصور
الصور (الشخصيات، الأرضيات، الفخاخ، الفواكه) من حزمة **Pixel Adventure 1** لصاحبها Pixel Frog، وهي مضمّنة داخل الملف بصيغة base64. راجع ترخيص الحزمة في صفحتها على itch.io قبل أي استخدام تجاري.
